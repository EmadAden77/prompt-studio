## Measurement notes

- Old output is `buildPositivePrompt()` from the current legacy engine. New output is the Phase 3 resolver → `buildCanonicalV3()` → Phase 4 OpenAI image adapter pipeline.
- Word counts use whitespace-delimited tokens.
- “Repeated facts” is a deterministic semantic-signal metric. The test splits prompts into factual units, checks stable categories such as identity reference, eyewear, camera device/geometry, lighting, physical plausibility, LHD geometry, steering wheel, center console, driver door/window, group count and accidental event, then counts category appearances beyond the first. It is deliberately stricter than exact-string duplicate detection.
- Conflict rate is the number of recorded conflict/correction events divided by seven cases and normalized to 100 cases. It is not a generator-quality score; it measures how much input normalization/resolution work each pipeline records for this corpus.
